# Coffee Shop Project

This repository contains a dual-layered approach to a Coffee Shop application, including a backend management logic built with Java and a frontend user interface built with HTML and CSS.

## 🚀 Project Components

### 1. Backend: CoffeeShop.java
A Java application designed to handle the core logic of a coffee shop. 
* **Key Features:** Likely includes menu item management, order processing, or price calculations.
* **Concepts Used:** Object-Oriented Programming (OOP), console I/O, and basic data handling.

### 2. Frontend: coffee.html & coffee.css
A visually appealing landing page for the coffee shop.
* **Web Design:** Uses semantic HTML for structure and custom CSS for a modern aesthetic.
* **UI/UX:** Focuses on a clean layout to showcase menu items and shop branding.

## 🛠️ Built With
* **Java:** For backend logic and processing.
* **HTML5:** For the web structure.
* **CSS3:** For styling, layout, and responsiveness.

## 📖 How to Use

### Viewing the Web Page
1. Download or clone the repository.
2. Open `coffee.html` in any web browser.
3. Ensure `coffee.css` is in the same folder for the styling to load correctly.

### Running the Java Program
1. Open your terminal.
2. Compile the program:
   ```bash
   javac CoffeeShop.java
